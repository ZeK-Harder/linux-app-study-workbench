# P1 · devlogstat 设备日志统计 CLI（3 周）

## 目标

解析仪器/设备日志（时间戳 / 通道 / 状态码），统计通道与状态 TopN。

## 技术轴

文件 IO、getopt、字符串处理、模块化、单元测试

## 完成标准

- **MVP**：解析 10 万行、通道/状态统计、单测全绿
- **进阶**：1GB 流式处理、多文件
- 理解清单要点：为什么不整读、缓冲区怎么定、getopt、错误返回、流式统计

## 验收

MVP + 理解清单 8/10 + 数据流图 + 3 分钟口述稿（照 `验收/项目验收模板.md`）。

## 交付结构
