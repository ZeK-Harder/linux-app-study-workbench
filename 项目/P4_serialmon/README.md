# P4 · serialmon 串口采集工具（4 周）★ 可投递

## 目标

串口读帧（帧头 + 长度 + 数据 + CRC16）→ CSV / SQLite，拔插不崩；用 C++ 类设计。

## 技术轴

termios、CRC16、超时、文件 / SQLite、C++ 类设计

## 完成标准

- **MVP**：1 小时真实数据正确、拔插不崩
- **进阶**：SQLite 落库、Modbus RTU 从站模拟（pymodbus）
- 理解清单要点：串口参数（波特率/数据位/校验/流控）、帧边界、CRC 原理、拔插恢复

## 硬件

STM32F407 板载 CH340 优先；没有就用 socat 虚拟串口对；需要再买 USB-TTL / USB-RS485。

## 验收

MVP + 理解清单 8/10 + 1 小时数据 + 3 分钟口述稿。
