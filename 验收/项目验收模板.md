# 项目验收模板

> 每个新项目复制一份到项目目录（`验收记录.md`），逐条打勾。**MVP 不过 = 项目没做完；理解清单不过 = 没学会。**

## 项目信息

- 项目：
- 日期：
- 对应计划段：（P1 / P2 / P2.5 / P3 / P4 / P5 / P6）

## 一、MVP 验收（能跑 + 有数据 + 有测试）

- [ ] 一条命令 / 双击能跑（README 写清环境与步骤）
- [ ] 关键指标有实测数字（不是“应该可以”）
- [ ] 核心逻辑有单元测试或自动化断言
- [ ] 代码在仓库里（git 提交可读）

## 二、理解验收（弄懂）

- [ ] 数据流图画得出（不看代码讲 2 分钟）
- [ ] 3 条关键机制讲得清（为什么 / 删了会怎样 / 换个做法）
- [ ] 10–15 题追问清单，随机抽 5 题答对 ≥4
- [ ] 3 条踩坑记录（现象 → 定位 → 根因 → 修复）

## 三、产物清单

- [ ] 代码 + Makefile/构建脚本
- [ ] README（是什么 / 怎么构建 / 怎么跑 / 边界）
- [ ] docs/理解清单.md
- [ ] 数据流图（图或文字版均可）
- [ ] 3 分钟 demo 视频 / 口述稿

## 四、结论

- ⬜ 通过（可进下一个项目）
- ⬜ 退回补（缺哪项补哪项）
